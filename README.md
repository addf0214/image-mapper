# Image Mapper

Windows 本地照片定位工具：PixTrack GPX 自动定位，或地图指定同一地点批量定位。支持 Sony ARW / JPG / JPEG。

## 启动

需要 Node.js 22.12+ 和 npm；首次安装联网下载 Electron、ExifTool 和本地地理时区数据，不需要自行安装 ExifTool。

```powershell
cd C:\Users\Allen\Development\image-mapper
npm install
npm start
```

若 npm 跳过了 Electron 下载脚本，先执行 `node node_modules/electron/install.js`。

## 使用

1. 点击“添加照片”，通过缩略图、文件名和数量确认照片。空列表首次添加默认全选；点击缩略图可勾选／取消，也可全选、取消选择。已有照片时继续添加，新照片不自动勾选；重复添加同一文件不会重复显示。
2. 选择 GPX 模式并添加 PixTrack 轨迹，或选择手动模式，搜索地点后点击地图／拖动标记调整。已知 WGS84 坐标也可补充输入。
3. 点击“写入选中的 N 张”，仅处理勾选项。整批结束后，成功和已有 GPS 的照片自动移出工作区；未选项、失败、无法匹配和待选择匹配的照片留下。已有 GPS 保留原位置，应用没有覆盖选项。
4. 处理结束取消所有勾选。继续选择剩余照片；手动模式需重新确认下一批地点，地图视野保留，GPX 也保留。最近一次结果的逐文件详情可展开查看。
5. 若某张照片有多个合理的时间／位置匹配，先保持原文件；在其照片卡片中选择候选并点击“采用此匹配”。处理其他照片不会清掉该候选。
6. × 可移除误选，“清空待处理列表”可换一批；都只清除应用列表，不删除照片文件。

**相机应始终记录拍摄地当地时间，包括旅行中跨时区后的拨钟。**无需手填相机时区，可以在同一批处理不同时区的照片。应用从地点确定时区，按拍摄日期处理夏令时。原墙上时间和亚秒保持不变，只补充 OffsetTimeOriginal。缺少有效拍摄时间或当地时间不存在时跳过，不使用电脑时区、旧偏移或文件修改时间猜测。

缩略图只用于确认选择：JPEG 在内存中缩小，ARW 提取内嵌 PreviewImage，不解码完整 RAW。没有内嵌预览时显示“无可用缩略图”，仍可定位。

GPX 使用带 Z／偏移的轨迹时间，从轨迹点地点获取候选时区，再按照片墙上时间寻找匹配并核对匹配位置的时区。仅在同一连续段内插值，相邻点上限 **120 秒**；不跨段、无时间点或长空白，不外推。若轨迹在某个狭窄时区未记录任何点，不能保证定位该区内的照片。照片与轨迹时间不匹配会报告跳过，不会自动筛选整个文件夹；该功能尚未决定。

直接修改所选原文件，ExifTool 使用 `-overwrite_original_in_place -P`，无永久整份照片备份、不重编码图像。写入 WGS84 经纬度、GPSMapDatum 与拍摄时区；GPX 模式另外写照片对应的 UTC GPS 时间。第一次定位时清理不完整 GPS 残留。手动模式不伪造高度、精度、速度或方向。

## 地图与时区数据

Leaflet + OpenStreetMap 标准底图 + Nominatim 搜索，无需 API Key，底图和搜索都按 WGS84 使用。不要把高德 GCJ-02 或百度坐标直接填入补充坐标栏。时区由本地 [geo-tz](https://github.com/evansiroky/node-geo-tz) 地理边界数据查询，日期偏移由 Temporal / 运行时 IANA 规则计算；边界和地方时制可能有多个候选，应用会提示选择，不依据经度简单划分时区。

**请遵守 [Nominatim 搜索政策](https://operations.osmfoundation.org/policies/nominatim/) 和 [OSM 瓦片政策](https://operations.osmfoundation.org/policies/tiles/)**。搜索仅由用户点击触发，无自动补全，间隔至少 1.1 秒、单请求执行并缓存本次会话结果。瓦片署名可见，使用应用标识和 Chromium 持久 HTTP 缓存，无预下载、离线地图或自动重试。照片、缩略图和元数据均在本地处理；地图服务仅收到搜索文字、当前地图请求和连接信息。请勿输入保密／个人信息。

公共服务可能限流或不可用，不保证所有大陆和海外网络可达；地图／搜索失败和超时明确报告。维护者可以用 `IMAGE_MAPPER_TILE_URL` 和 `IMAGE_MAPPER_SEARCH_URL` 切换 HTTPS 的 OSM 衍生瓦片模板与 Nominatim 兼容接口；替代服务必须输出 WGS84，允许此用途，并适用当前署名。

同一连续段内，同时间且同经纬度的重复点会合并，结果显示合并数量；同时间不同位置或时间倒序仍报错。
